# Python Crash Course Practice

This repository contains my chapter‑wise practice files from Eric Matthes’s book *Python Crash Course*.  
Each folder corresponds to a chapter and its exercises.

---

## 📚 Contents

- **Chapter 1: Getting Started**  
  Introduction to Python, installation, and running code.

- **Chapter 2: Variables and Simple Data Types**  
  Working with strings, numbers, and naming rules.

- **Chapter 3: Lists**  
  Creating, modifying, and iterating through lists.

- **Chapter 4: Working with Lists**  
  Looping, slicing, and list comprehensions.

- **Chapter 5: If Statements**  
  Conditional logic and Boolean expressions.

- **Chapter 6: Dictionaries**  
  Key‑value pairs, nesting, and iteration.

- **Chapter 7: User Input and While Loops**  
  Interactive programs and loop control.

- **Chapter 8: Functions**  
  Defining, calling, and passing arguments.

- **Chapter 9: Classes**  
  Object‑oriented programming basics.

- **Chapter 10: Files and Exceptions**  
  Reading/writing files and handling errors.
